# Fardeen PP — Portfolio

Portfolio website for Fardeen PP, video editor & videographer (Calicut, Kerala).
Static site: plain HTML/CSS/JS + Three.js (vendored). No build step.

## Run locally
```
python3 -m http.server 8999     # then open http://localhost:8999
```

## Structure
- `index.html`, `css/style.css`, `js/main.js` — page, styles, interactions
- `js/hero3d.js` — full-page WebGL background (Three.js in `vendor/`)
- `js/data.js` — video/photo list (generated by `tools/build-data.py`; edit titles in that file)
- `assets/` — web-optimised videos, posters and photos
- `tools/build-assets.py` — re-creates `assets/` from the original footage folders (needs ffmpeg + Pillow)

## Deploy
Deployed on Vercel as a static site (no framework, no build command, output directory = repo root).
